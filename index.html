과학 문제은행

2022 개정 교육과정 중1부터 고3까지, 시험지 만들기부터 채점까지 한곳에서.

📥 JSON 한번에 불러오기 단원별 문제·기출 문제(변형 포함)·시중 교재·EBS·백업 파일을 섞어서 골라도 알아서 나눠 넣습니다.

🎯 단원별 문제 추출 및 DB 관리

JSON 파일을 여러 개(또는 폴더째) 올리면 종류를 보고 단원별 문제·기출 문제·시중 교재로 알아서 나눠 합칩니다(중복 문제는 제외). 그림이 있는 문제도 이 브라우저에 자동 저장됩니다.

📘 시중 교재 문제

변환한 교재 폴더(OneDrive\Claude\JSON변환)를 한 번 불러오면 이 브라우저에 저장되고, 교과 → 교재 → 단원 순서로 문제를 고를 수 있습니다. 같은 파일을 다시 불러오면 새 내용으로 바뀝니다.

📝 추출 문제 검수 및 시험지 저장

문항·그림을 고친 뒤 시험지 저장을 누르면 이 브라우저의 출제 문제에 저장됩니다. 한글 파일이 필요하면 다운로드를 누르세요. (시험지 틀은 미리보기에서 선택)

그림 생성기PDF 시험지 → JSON → 흑백 이미지 → HWPX

PDF를 고르면 JSON으로 변환하고, 그림·그래프를 흑백 이미지(PNG)로 만든 뒤 시험지 미리보기에 끼워 넣습니다. 미리보기에서 바로 수정하고 HWPX로 저장합니다.

PDF 선택 → JSON 변환 → 이미지 생성 → 미리보기까지 한 번에 진행합니다. (JSON을 직접 넣으려면 아래 [JSON] 탭)

제목·문제 글·보기·선택지를 클릭해서 바로 고칠 수 있습니다. 고친 내용은 저장 결과에 그대로 들어갑니다.

PDF를 선택하거나 [JSON] 탭에 JSON을 넣어 주세요.

변환된 JSON입니다. 고친 뒤 [JSON 적용]을 누르면 미리보기가 다시 만들어집니다. (바뀐 그림만 다시 생성합니다)

HWPX (한글 문서)

제목, 문제, 보기, 선택지, 그림 이미지를 한글에서 열 수 있는 .hwpx로 저장합니다. 미리보기에서 고친 내용이 반영됩니다.

그림 PNG 전체

생성된 흑백 이미지를 문항 id 이름의 PNG로 하나씩 내려받습니다.

기출 문제 · 기출 변형 문제 탭에 넣기

미리보기의 문항과 그림을 기출 문제 탭에 시험지로 저장합니다. API 키가 있으면 Gemini가 정답·해설을 달고, 변형 세트 수만큼 변형 문제를 만들어 기출 변형 문제 탭에 넣습니다. 그림이 있는 문항의 변형은 원본 그림을 그대로 씁니다. 만든 정답·해설·변형 문제는 꼭 검토해 주세요.
